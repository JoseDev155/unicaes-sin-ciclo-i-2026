## **Tema: Puesta en marcha de Sistemas Informáticos**
### Objetivo de la Unidad III

Comprender y aplicar los procesos clave en la implementación y puesta en marcha de sistemas informáticos (planificación, métodos, calidad, documentación, pruebas, capacitación, etc.).

### Fase de Implementación
#### Plan de implementación y puesta en producción

Elegir herramientas, entorno de desarrollo y lenguaje apropiado según las decisiones de diseño.

#### Métodos de implantación
  1. **Metodología en cascada:** Requisitos completos al inicio, diseño y p2lanificación secuencial.
  2. **Metodología ágil o de Scrum:** Cumplimiento en cortos plazos (**sprints**), involucrando al cliente.
  3. **Sure Step:** Implantación por fases (Análisis, diseño, construcción, implementación y objetivo).

#### Aseguramiento de la calidad mediante Ingeniería de Software

* **Propósitos:**
  * El usuario es el factor más importante para evaluar la calidad.
  * Es menos costoso corregir errores en fases iniciales.
* **Enfoques:**
  * Se debe diseñar con enfoque modular (descendente).
  * Documentar, probar, mantener y auditar el software.

#### Técnicas para elaborar manuales

* **Pseudocódigo:** Para representar la lógica de cada módulo.
* **Manuales de Procedimiento:** Pasos para transacciones e instrucciones para solucionar problemas.
* **El Método de Folklore:** Recopilar costumbres, anécdotas, proverbios y formas artísticas entrevistando y observando usuarios.

#### Pruebas Iniciales, caja blanca y caja negra

Se hacen durante todo el desarrollo para descubrir errores, evaluando el sistema como un todo funcional.

* **Caja Negra:** Pruebas funcionales, desde *fuera* del sistema (ej. Login incorrecto, escenario de uso).
* **Caja Blanca:** Pruebas estructurales, desde *dentro* del código (ej. cobertura de bucles, diagrama de código).

### Instalación y Administración de Sevicios, Terminales y Entorno Operativo. Capacitación y Entrenamiento de Usuarios

### Instalación, Capacitación y Evaluación

Esta etapa consiste en preparar toda la infraestructura tecnológica necesaria para que el sistema funcione correctamente.

* **Instalación del Sistema**
  Incluye:
  * Servidores.
  * Bases de datos.
  * Redes.
  * Aplicaciones.
  * Servicios web.
  * Seguridad.
* **Entorno Operativo**
  Puede ser:
  * Local.
  * Cliente-servidor.
  * Nube.
  * Híbrido.
  Tecnologías modernas usadas en 2026:
  * **Amazon Web Services**
  * **Microsoft Azure**
  * **Google Cloud**
* **Administración de Servicios**
  Se administran:
  * Servidores web.
  * APIs.
  * Contenedores.
  * Bases de datos.
  * Balanceadores de carga.
  Tecnologías comunes:
  * **Docker**
  * **Kubernetes**

### Capacitación y Entrenamiento de Usuarios

**Capacitación de Usuarios**

Busca que los usuarios:

* Comprendan el sistema.
* Reduzcan errores.
* Aprovechen funcionalidades.

**Métodos Modernos de Capacitación**

**a) Capacitación presencial**<br />
Instructor directo.

**b) E-learning**<br />
Uso de plataformas online virtuales.

**c) Simuladores interactivos**<br />
Ambientes de práctica.

**d) Microlearning**<br />
Capacitaciones cortas y específicas.

### Revisión y Evaluación del Comportamiento del Sistema

Consiste en medir:

* Rendimiento
* Seguridad
* Disponibilidad
* Uso de recursos
* Experiencia del usuario

### Indicadores Comunes

| Indicador                | Descripción           |
|--------------------------|-----------------------|
| Tiempo de respuesta      | Velocidad del sistema |
| Disponibilidad           | Tiempo activo         |
| CPU/RAM                  | Uso de recursos       |
| Errores por minuto       | Estabilidad           |
| Satisfacción del usuario | Calidad percibida     |

### Conclusión

Las organizaciones modernas usan metodologías ágiles, automatización, DevOps y Cloud para lograr sistemas:

* Escalables
* Seguros
* Disponibles
* Mantenibles
* Adaptables a los cambios tecnológicos
